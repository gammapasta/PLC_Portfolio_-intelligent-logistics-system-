# PLC 기반 지능형 자동화 물류 시스템
 **C언어의 구조체(Structure) 개념을 도입한 데이터 기반 재고 관리 및 위치 제어 시스템**

## 1. 프로젝트 개요
*   **프로젝트 명:** MELSEC-Q 시리즈 기반 지능형 소재 분류 및 적재 시스템
*   **프로젝트 목표:**
    *   기존의 단순 수량 카운팅 방식을 탈피하여, 소재의 **위치(Location)** 와 **속성(Property)** 을 분리하여 Ladder로 구현.
    *   C언어의 구조체(Struct) 개념을 래더(Ladder) 로직에 적용하여 효율적인 재고 관리 및 입출고 프로세스 구축.
*   **주요 기능:**
    *   좌표 데이터를 활용한 서보 모터 정밀 위치 제어
    *   소재 속성(금속/비금속)에 따른 자동 분류 및 배출
    *   실시간 재고 현황 모니터링 및 HMI 제어
    *   인터락 및 예외 처리 로직 구현

## 4. 핵심 알고리즘
**데이터 구조화 설계**

### 4.1. 설계 컨셉: C언어 구조체 방식의 데이터 매핑
* 기존의 구현 방식은 물건의 개수만 카운트하여 구현하여 특정 위치에 어떤 물건이 있는지 파악하기 어려웠지만, 이번 프로젝트에서 **"어디에(위치 정보)"**, **"무엇이(속성 정보)"** 있는지 관리를 위해 **배열과 구조체 개념**을 도입.
* 추후 [무게], [불량 유무] 등 다른 속성들을 쉽게 추가 가능함.
  
<br>

### **구현 방식**
<img src="./포트폴리오자료/핵심알고리즘1.png" alt="핵심알고리즘1" width="600">
<img src="./포트폴리오자료/핵심알고리즘2.png" alt="핵심알고리즘2" width="600">



 *   D 레지스터 블록을 하나의 '셀(Cell)'로 정의.
 *   예: [1행 1열] = **D11**(점유 상태, K0/K11) + **D13**(재질 코드, K0:비어있음/K1:비금속/K2:금속)
 *   이를 통해 단순 적재를 넘어 특정 재질 추적 및 재고 관리가 가능해짐.

<br>

### 4.2. 지능형 적재(입고)
<img src="./포트폴리오자료/핵심알고리즘3사용자입고.png" alt="사용자입고" width="600">
<img src="./포트폴리오자료/핵심알고리즘4지능형적재.png" alt="능형적" width="600">

*   **사용자 지정 입고:** HMI에서 특정 셀 지정 시, 비교 명령어(=)로 해당 셀(D11)이 비어있는지(K0) 사전 검증 후 예약 레지스터(D510)에 저장.
*   **자동 빈자리 찾기:** 판별 로직을 통해 1번 창고부터 순차적으로 탐색, 빈 곳 발견 시 해당 위치 데이터를 D2402(목표 위치값)에 전송하고 서보 기동(ZP). 
*   D1019(입고 비트값)을 활용하여, 사이클 마다 한번의 작업만 가능하도록 제어함 

<br>

### 4.3. 지능형 배출(출고)
<img src="./포트폴리오자료/핵심알고리즘5지능형배출.png" alt="지능형배출" width="600">

*   **기능 1 (지정 배출):** 특정 위치(예: 4번 창고) 지정 시 데이터 확인 후 배출.
*   **기능 2 (순차 배출):** 순차적으로 창고에 남아있는 물건 배출.
*   **기능 3 (속성별 자동 배출 - Filtering):**
    *   **비금속 배출:** 데이터 뒷자리가 1인 셀을 검색하여 출고.
    *   **금속 배출:** 데이터 뒷자리가 2인 셀을 검색하여 출고.
*   **인터락:** 배출 동작 중이거나 창고 데이터가 비어있을 경우 동작 금지.

<br>

### 4.4. 공정 데이터 분석 및 예외 처리
<img src="./포트폴리오자료/터핵심알고리즘6공정데이터분석.png" alt="공정데이터분석" width="600">

*   **평균 그래프 구현:** SUM(D4003)과 COUNT(D4004) 레지스터 분리하여 항상 평균 그래프가 직선을 유지.
*   **Zero Division 방지:** 나눗셈 연산 시 SM400(Always ON)과 AND 연산, 분모가 0보다 클 때만 연산을 수행하여 PLC 에러 방지.

## 6. 서보 모터 제어

### 6.1. 서보 파라미터 설정
<img src="./포트폴리오자료/서보세팅2.png" width="600">

*   **제어 방식:**
    *   **ABS (Absolute):** 원점 기준 절대 위치 이동 (지정된 창고 위치로 이동 시 사용).
    *   **INC (Incremental):** 현재 위치 기준 상대 이동 (적재 및 배출 시 사용).
*   **주요 파라미터:**
    *   ACC/DEC TIME: 가감속 시간을 조절하여 진동 억제 및 사이클 타임 단축 가능.
    *   Positioning Address: 위치값 설정 ($\mu m$ 단위).

### 6.2. HG-KR13J 모터 선정 이유
*   **고해상도 제어:** 22-bit 엔코더 탑재로 나노미터 단위 정밀 제어 가능.
*   **고응답성:** 저관성(Low Inertia) 설계로 창고 입출고와 같이 잦은 가감속이 필요한 공정에 적합.

## 7. 트러블 슈팅 (Troubleshooting)

### 이슈 1: 이중 코일(Double Coil)로 인한 오동작
*   **증상:** 금속 배출 후 비금속 배출 시퀀스 진입 시, 간헐적으로 특정 실린더가 오동작하거나 반응하지 않음.
*   **원인 분석:** 로직이 방대해짐에 따라, 내부 릴레이가 적재 로직과 배출 로직에서 중복 할당된 "이중 코일" 현상 확인.
*   **해결:**
    *   기능별 주소 대역을 명확히 리맵핑 (적재: M2000번대, 배출: M3000번대).
    *   출력부와 조건부 접점을 구조적으로 분리하여 충돌 방지.

### 이슈 2: 모션 모듈(QD77) 통신 딜레이 및 명령 무시
*   **증상:** 연속 공정 시, 이전 위치결정이 끝나자마자 다음 명령(ZP.PSTRT1)을 실행하면 서보가 반응하지 않음.
*   **원인 분석:** 위치결정 모듈이 'Busy' 상태에서 'Ready' 상태로 전환되는 하드웨어적 처리 시간보다 PLC 스캔 타임이 빨라 명령이 누락되는 현상.
*   **해결:**
    *   동작 전환 사이에 약 0.5초(T K5)의 **인터벌 타이머** 추가.
    *   X접점이 확실히 완료 된 후 다음 명령이 실행되도록 설정함.
    *   (ZP.PSTRT1 U7 D3000 M3000, M3000 AND ^M3001 -> 완료신호)

## 8. 안전 설계


### 8.1. 하드웨어 안전 설계
*   **FLS / RLS (Limit Switch):**
    *   **B접점(NC) 적용:** 케이블 단선 시 즉시 회로가 차단되어 장비가 정지하도록 설계. (B접점의 경우 케이블이 끊어질경우 전기가 통하지 않으므로 안정성을 높인다.)
    *   물리적 한계점 도달 시 서보 강제 정지.

### 8.2. 소프트웨어 안전 설계 
*   **Initialization** 시스템 시작시 모든 실린더를 초기 위치로이동.
*   **Safty Lock** 모든 시스템이 초기위치가 아니라면 작동 불가.
*   **Timeout Error:** 실린더나 모터가 명령 후 일정 시간 내에 동작 완료 신호를 보내지 않으면 에러 발생 및 부저 출력.
*   **Interlock:**
    *   흡착 실린더 전진(On) 중에는 수평/수직 이동 모터 동작 불가.
    *   배출 컨베이어 가동 중에는 신규 배출 금지.

## 9. 유지보수 매뉴얼

1.  **조작 방법:**
    *   [로그인] 후 메뉴 진입 가능.
    *   [장비 페이지]에서 MPS 장비 점검 가능.
    *   [서보 페이지]: 수동으로 서보모터 제어 가능. 
        *   JOG 상승: 모터 역회전
        *   JOG 하강: 모터 정회전
        *   작업 시작 스위치: 소재가 있으면, 창고로 적재. 창고가 포화상태면 니머지 소재들은 배출.
        *   수동으로 [원점 복귀] 및 [고속 복귀]가능.
        *   에러번호, 경고번호가 나오면 서보모터 동작 정지 -> 에러 초기화 버튼으로 에러 리셋.
        *   비상 정지: 모든 실린더는 후진, 서보 모터는 정지. 정지 버튼을 다시 누르면 이어서 진행.
    *   [창고1 페이지] 가공 물품의 [가공 시간]과 [가공 횟수] 설정가능.
    *   [창고2 페이지] 수동으로 원하는 위치에 적재 및 배출 가능.
        *   금속 배출, 비금속 배출: 소재 특성에 맞게 순차 배출.
        *   순차 배출: 오름차순으로 순차 배출.
    *   [그래프 페이지]: 가공 완료 시간(초 단위), 가공 평균 시간(초 단위), 적재까지 완료 시간(초 단위), 적재까지 완료 시간의 평균 시간(초 단위) 그래프를 볼 수 있다.


2.  **에러 조치:**
    *   **알람 발생 시:** 소재가 스토퍼 센서에 감지 되었는지 확인.
        *   최후의 방법으로 PLC 리셋 후 다시시작.
    *   **서보 에러:** 서보 페이지에서 에러 코드 경고 코드 확인 후 매뉴얼 참조 및 초기화 버튼 누르기.
